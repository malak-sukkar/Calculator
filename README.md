# Calculator

A small browser-based calculator with a responsive dark interface.

## Features

- Number and decimal buttons
- Basic arithmetic operation buttons
- Clear and delete controls
- Responsive layout

## Run locally

Open `index.html` in a web browser. No installation or build step is required.

## Built with

- HTML
- CSS
- JavaScript

The interface uses Google Fonts and Font Awesome from their CDNs. An internet connection is needed to load those fonts and icons.
